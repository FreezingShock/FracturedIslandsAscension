02What I noticed

  1. Day/night and seasons are cosmetic. ClockConfig.at() returns isNight and season, but only ClockService and ScoreboardController read them; no mob, drop or skill reacts to time.
  2. Fishing and Farming have XP tables, zones and collections but no action. ZoneConfig.SKILLS and StatisticsConfig list them (e.g. Fishing Kelp), but nothing calls AddXP for them; only LootService.reward feeds XP (entry.xp).
  3. Enemies now fight back, players cannot avoid. EnemyAI/EnemyAttacks/EnemyTelegraphController (3.74.1: combo/lunge/slam, telegraphs) exist, yet the only defence is Defense stat; grep finds no dodge/i-frame code.
  4. Stamina has one consumer. ResourceConfig Stamina is spent only by sprint (MovementConfig.sprint.resource).
  5. Saved-data pattern is ready for new fields: PROFILE_TEMPLATE in SkillsDataManager (e.g. _Rewards) with Reconcile backfill.

03The ideas

1

Dodge Roll

S · Small⌨ F (free)✪ TOP PICK

Tap F to roll a short distance, spending Stamina, and enemy attacks that land during the roll miss. Timing a roll through a telegraphed slam finally feels like SkyBlock-meets-Souls combat.

☄Why now

3.74.1 added telegraphed enemy attacks (EnemyAttacks, EnemyTelegraphController), but the player has no active defence; Stamina is only used by sprint.

✎Goal

Client sends intent on F; server validates Stamina, cooldown and state, dashes the character and grants a short i-frame window that EnemyAttacks honours.

⚒Files

  • Shared/Modules/Stats/MovementConfig.lua (add dodge)
  • Server/Stats/MovementService.lua (validate, spend, set attribute Invulnerable expiry)
  • Client/World/SprintController.client.lua (send intent, local dash feel). If the hit check needs a one-line read of the attribute, it is in Server/Combat/EnemyAttacks.lua (4th file only if unavoidable)

❁Config

MovementConfig.dodge = { key = "F", staminaCost = 25, distance = 14, duration = 0.28, iframes = 0.22, cooldown = 0.9, sound = "" }; library -> type -> override: dodge.types = { light = {...}, heavy = {...} } picked by equipped armor weight later, per-player override via stat DodgeDistance.

✖Out of scope

Directional dodge animations, armor-weight types, perfect-dodge rewards, mobile button.

ቾPlaceholders

Roll animation id and whoosh sound as empty slots. Key F.

✔Verification

  • Fire the dodge remote: Stamina drops by staminaCost
  • character moves about distance studs
  • attribute DodgeUntil is set then expires after iframes
  • a second fire inside cooldown or with Stamina below cost is rejected
  • an enemy attack resolved during DodgeUntil deals 0 damage and one after it deals damage

☠Risk

Server-driven movement on a client-owned character rubber-bands; let the client move locally and have the server only validate and own the i-frame window.

2

Fishing Holes

M · Medium⌨ no key

Walk up to glowing fishing holes, cast with a click, wait for the bobber to dip and hit the prompt in time to reel in a catch. Better rods and Fishing levels pull rarer fish, kelp and treasure.

☄Why now

Fishing is one of the six skills with zone art, a statistics chain and level rewards, and it is the only one with literally no source of XP (ZoneConfig.SKILLS.Fishing, StatisticsConfig).

✎Goal

First non-combat loop: server owns the cast, bite timer and catch roll; client only shows the bobber and sends cast/reel intent.

⚒Files

  • Shared/Modules/Stats/FishingConfig.lua (new)
  • Server/Stats/FishingService.lua
  • FishingInit.server.lua (new, RemoteEvent with type-checked inputs and RateLimiter)
  • Client/World/FishingController.client.lua (new), reuse LootService.spawnDrop
  • SkillsDataManager.AddXP
  • StatisticsDataManager

❁Config

FishingConfig.holes[<tag>] (CollectionService tag on a Part) -> type (pond/sea/lava) -> per-hole override: { biteSeconds = {3,8}, reelWindow = 0.8, pools = { common = {weight, entries}, treasure = {...} }, xp = { skill = "Fishing", amount = 12 } }; fishingSpeed and a rod item field power scale biteSeconds.

✖Out of scope

Fishing rod crafting, sea creatures as enemies, a bait system, minigame art beyond one exclamation billboard.

ቾPlaceholders

Splash/bite sounds, bobber model and rod cast animation as silent slots (a Part sphere stands in). No key (mouse click).

✔Verification

  • Server-side call for a cast near a tagged hole opens a cast with a bite time inside biteSeconds
  • reel inside reelWindow after bite returns a catch entry from the pool and calls AddXP once
  • reel before bite or after the window gives nothing
  • casting 10x in 1s hits the rate limit
  • a cast from beyond maxRange is rejected

☠Risk

Lots of new surface (cast state per player); an abandoned cast on death or leave must be cleaned up or it leaks a task.

3

Night Hunt

M · Medium⌨ no key

When night falls on the island, monsters in the wild glow with a purple aura, hit harder and drop much more; the scoreboard and action bar warn you at dusk. Brave players farm at night, careful ones wait for dawn.

☄Why now

The clock (3.73.4) now produces isNight, seasons and Lighting.ClockTime, yet nothing reacts to it. Enemy levels/tags (EnemyTags) already give a way to mark a boosted mob.

✎Goal

Time-of-day modifiers declared in data: a Night tag and stat multipliers on spawn, higher drop chance/XP on kill, and the nameplate tag shows while it applies.

⚒Files

  • Shared/Modules/Config/ClockConfig.lua (add modifiers)
  • Server/Combat/EnemyService.lua (apply at spawn and on phase flip via ClockService attribute)
  • Server/Combat/LootService.lua (read multiplier in roll/reward)
  • Shared/Modules/Combat/EnemyConfig.lua (per-enemy timeModifiers override), tag icon via EnemyTags
  • tools/gen_tag_icons.py

❁Config

ClockConfig.modifiers.night = { hp = 1.25, damage = 1.3, dropChance = 1.5, xp = 1.4, tag = "Moonlit" } (library) -> ClockConfig.modifiers.seasons.Winter = {...} (type) -> EnemyConfig.types.<id>.timeModifiers = { night = false } (override to opt out).

✖Out of scope

Special night-only mobs, weather, blood moon events, per-zone overrides.

ቾPlaceholders

Aura colour only; tag icon from gen_tag_icons; no sound.

✔Verification

  • Set workspace ClockEpoch so isNight is true
  • a freshly spawned eligible mob has attribute Tag_Moonlit and Humanoid.MaxHealth = base*hp
  • killing it calls AddXP with amount*xp
  • a mob whose config sets night = false gets no tag
  • flipping to day removes the tag and restores MaxHealth ratio

☠Risk

Changing MaxHealth on live mobs mid-fight can desync the nameplate bar and leash heal; apply at spawn and only re-scale outside combat.

4

Seasonal Farm Plots

L · Large⌨ no key

Claim a farm plot, plant seeds and watch crops grow over in-game days; each season favours different crops and winter kills the field unless you chose hardy plants. Harvest for Farming XP, crops for Coins and rare mutations.

☄Why now

Farming is a core skill with zones and collections but no loop, and the 3.73.4 calendar (8-day months, four seasons) was built for exactly this and is unused by gameplay.

✎Goal

Persistent plots: plant, grow by in-game days from ClockConfig, harvest. Growth is computed from saved plant day numbers (no timers), so it progresses offline.

⚒Files

  • Shared/Modules/Stats/CropsConfig.lua (new)
  • Server/Stats/FarmService.lua
  • FarmInit.server.lua (new)
  • Server/Data/SkillsDataManager.lua (PROFILE_TEMPLATE._Farm = { plots = {} }, Reconcile backfills)
  • Client/World/FarmController.client.lua (new, prompts + stage visuals)
  • ClockConfig read-only

❁Config

CropsConfig.crops.<id> = { growDays = 4, stages = 4, seasons = { Spring = 1.0, Summer = 1.2, Autumn = 0.8, Winter = 0 }, yield = {...}, xp = {skill="Farming", amount=8}, seed = "item id" } (library) -> types (grain/root/flower) -> per-crop override; mutations = { { chance = 0.02, id = ..., yieldMult = 3 } }; plots tagged FarmPlot in Studio with attribute size.

✖Out of scope

Sprinklers, minions, fertilizer items, selling UI (Island Merchant is separate), mobile controls.

ቾPlaceholders

Plot/crop models, plant and harvest sounds as placeholder Parts and silent slots; no key (ProximityPrompt).

✔Verification

  • Plant on an owned plot
  • profile _Farm.plots[id] stores crop and the clock day index
  • advance ClockConfig time by growDays and the stage reads stages
  • harvest before ripe returns nothing and keeps the crop
  • harvest when ripe adds yield items and calls AddXP once
  • in Winter growth rate is 0 and an unprotected crop is removed
  • reconnecting preserves state
  • a missing _Farm field is backfilled by Reconcile

☠Risk

Saved plot data plus a world calendar that resets per server (ClockEpoch): growth must be tied to a persisted real-time or server-independent day count, not server boot time, or crops regrow wrongly on a new server.

04Recommendation

Build Dodge Roll first: it is the cheapest idea, makes the brand-new enemy attacks fun immediately, and needs no saved data. Second is Night Hunt (uses the unused clock cheaply), third Fishing Holes, and Seasonal Farm Plots last because the ClockEpoch persistence problem should be decided before it is built.
